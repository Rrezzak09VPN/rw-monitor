## [1.0.0b1] — 2026-11-11

Первая публичная бета-версия.

### Добавлено

- **Подписки.** Загрузка клиентской подписки Remnawave по ссылке; форматы: список ссылок (base64 и открытый), Xray JSON, Mihomo/Clash YAML, sing-box JSON; протоколы VLESS, Trojan, Shadowsocks, Hysteria2, VMess (в ссылках). Определение формата по содержимому, объединение нескольких форматов, дедупликация, распознавание записей-заглушек, поддержка панелей с лимитом устройств (HWID) с явным согласием владельца, автообновление, защита от случайного удаления серверов.
- **Проверки.** Четыре уровня: DNS (с подтверждением отказа несколькими резолверами), TCP/QUIC, TLS (с воспроизведением фрагментации ClientHello из подписки), сквозная проверка через одноразовый Xray-клиент с периодической загрузкой 128 КБ.
- **Состояния.** OK / SUSPECT / DOWN / RECOVERED / UNKNOWN; настраиваемые пороги и интервалы перепроверок; восстановление только после серии успешных проверок.
- **Защита от ложных срабатываний.** Самоконтроль сети и DNS мониторинга, заморозка состояний при собственных проблемах, сводное сообщение при массовом отказе, предупреждение о нестабильном сервере, отличие истёкшей подписки от падения серверов, учёт наблюдений только с интервалом по времени.
- **Cheburcheck.** Запросы только по подтверждённому падению или по кнопке; раздельный показ замеров сканеров и статических списков со статусом достоверности; кеш, ограничение частоты, суточный потолок, предохранитель, отложенная очередь с досылкой данных.
- **Telegram.** Доступ только владельца; инлайн-меню (статус, серверы, подписки, настройки, исключения, история, ручная проверка); исключения трёх видов; настройки из чата с сохранением в базе; работа Bot API через прокси, безопасная смена прокси; очередь уведомлений, переживающая обрыв связи и перезапуск.
- **Эксплуатация.** Служба systemd со сторожевым таймером; шифрование секретов в базе и маскирование в журнале; ежедневные резервные копии; ограничение срока хранения истории; команды `rwmon check-config`, `selftest`, `backup`, `restore`, `reset-proxy`, `genkey`.
- **Установка.** `install.sh` — установка и обновление одной командой на Ubuntu 24.04 с проверкой системы, запросом обязательных параметров, сохранением существующей конфигурации, резервной копией базы и возвратом к прежней версии при неудачном запуске; `uninstall.sh`.
- **Тесты.** 132 автоматических теста, включая стенд с настоящими серверами Xray и заменители панели Remnawave, Telegram Bot API, Cheburcheck и SOCKS5-прокси.

### Известные ограничения

- Проверки из российской сети, запуск под настоящим systemd и ряд транспортов (XHTTP, gRPC, HTTPUpgrade, mKCP) в этой версии не испытаны. Полный список — в [docs/TESTING.md](docs/TESTING.md#что-не-проверено) и в [README](README.md#известные-ограничения-и-проблемы).
